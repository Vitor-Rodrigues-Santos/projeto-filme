Projeto desenvolvido como atividade prática de desenvolvimento web front-end. Trata-se de uma landing page informativa sobre o filme **Pecadores** (*Sinners*), dirigido por Ryan Coogler e estrelado por Michael B. Jordan.

---

## 🎯 Visão Geral

O objetivo principal desta atividade é demonstrar o domínio das estruturas fundamentais do **HTML5**, garantindo semântica apropriada, acessibilidade básica e organização do código.

---

## 🛠️ Funcionalidades e Tags Utilizadas

A página faz uso dos seguintes elementos do HTML5:

- **Declaração e Meta Tags:** `<!DOCTYPE html>`, `<meta charset="UTF-8">` e `<meta name="viewport">` para responsividade básica e suporte a acentuação.
- **Hierarquia de Títulos:** `<h1>` para o nome do filme e `<h2>` para detalhar as especificações técnicas.
- **Mídia:** Tag `<img>` com atributo `alt` para acessibilidade na exibição do cartaz do filme.
- **Texto Semântico:** Tag `<p>` para apresentação da sinopse da obra.
- **Navegação Externa:** Tag `<a>` direcionando para a página oficial do filme no IMDb.
